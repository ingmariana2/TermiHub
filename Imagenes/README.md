# Carpeta de imágenes

Esta carpeta (`img/`) contiene todas las imágenes utilizadas en la página web.

Actualmente el sitio emplea iconos SVG y emojis en lugar de archivos de imagen, por lo
que no hay imágenes adicionales por ahora. Si más adelante agregas fotos o gráficos,
colócalos aquí y actualiza las rutas en `index.html` o en las hojas de estilo.
